# 数学·物理·化学·生物 隐含条件排查库与教材对照提示

本文件供 shenti-coach 按学科读取隐含条件排查库。四科共用同一套五类框架：①约束类 ②图形隐含类 ③结构信号类 ④术语定义展开类 ⑤二级结论类。以下类目是排查提示而非穷尽清单；具体知识点、定律表述仍受铁律6约束，不确定标"待核实"，禁止编造。教材按辽宁口径标注：物理、化学、生物均为人教版；具体节次不确定时只标到章并写"节次待核实"。

## 数学（人教B版，辽宁口径）

### 五类隐含条件排查库

① **定义域约束**：
- 分母 ≠ 0；偶次根式被开方数 ≥ 0；对数真数 > 0 且底数 > 0 且 ≠ 1；实际问题中变量为正。
- 定义域为 R 的偶次根式要求被开方数恒 ≥ 0；二次式对应判别式 ≤ 0（不是 < 0）。
- 分段函数、绝对值、含参函数的定义域要按参数分类讨论。

② **图形隐含性质**：
- 切线 ⊥ 过切点的半径；圆心到切线的距离等于半径。
- 三角形内角和 180°；外角等于不相邻两内角之和；两边之和大于第三边。
- 对称轴、开口方向、顶点、渐近线、离心率范围；图象过定点。
- 圆锥曲线中“焦点弦/中点弦/垂直/相切”对应的几何关系。

③ **结构信号**：
- “任意 x” → 恒成立 / 求最值；恒成立常用分离参数或判别式。
- “存在 x” → 值域交集非空；存在性常用构造函数求值域。
- “恒成立” → 分离参数或判别式；“有解” → 值域与目标区间相交。
- “至少/至多/唯一” → 补集思想或计数边界。
- “充分不必要/必要不充分” → 集合真包含关系。

④ **术语定义展开**：
- “奇函数” → f(-x) = -f(x)，且定义域关于原点对称（含 0 时 f(0) = 0）。
- “偶函数” → f(-x) = f(x)，定义域关于 y 轴对称。
- “单调递增” → 定义式 f(x1) < f(x2)（x1 < x2），或导数 ≥ 0 且不恒为 0。
- “相切” → 判别式 = 0，或导数斜率相等且函数值相等。
- “周期函数” → 存在 T ≠ 0 使 f(x+T) = f(x)。
- “零点” → f(x) = 0 的根，不是点坐标。

⑤ **二级结论/常见引理**（逐条标【二级结论】）：
- 复合函数单调性“同增异减”。
- 二次函数在闭区间上的最值按对称轴与区间位置分类。
- 基本不等式求最值必须验证“一正二定三相等”。
- 数列中 a_n 与 S_n 的关系 a_n = S_n - S_{n-1}（n ≥ 2），须单独验证 n = 1。
- 圆锥曲线焦点弦、中点弦的常用结论；导数不等式放缩的常见模板。

## 物理

### 五类隐含条件排查库

① 理想化与模型约束：
- "光滑"→无摩擦；"粗糙"→必须考虑摩擦。
- "轻绳/轻杆/轻弹簧"→质量不计；"轻绳"只能拉不能压，"轻杆"可拉可压。
- "质点/点电荷"→忽略形状大小；"理想气体"→忽略分子势能。
- "缓慢"移动→准静态过程，每一时刻近似平衡。
- "不计空气阻力"→只受重力（抛体）；"接地"→电势为零。
- "斜向上/斜向下的拉力或推力"→支持力 N=mg∓Fsinθ，不等于 mg，摩擦力 f=μN 随之改变。
- 斜向下推时 N=mg+Fsinθ，支持力变大、摩擦力也变大；斜向上拉时 N=mg−Fsinθ。
- "静止"→先判断能否被拉动：把驱动力与最大静摩擦比较，未超过则仍静止，不能直接套滑动摩擦公式。

② 图形隐含性质：
- v-t 图：斜率=加速度，面积=位移；x-t 图：斜率=速度。
- 电路图：串并联结构决定电流电压分配；电表内阻是否理想。
- 受力图/运动轨迹：几何关系（角度、相似三角形）常是隐藏方程。
- 磁场图：磁感线方向、左手/右手定则的适用对象。
- 平抛/类平抛：水平方向匀速、竖直方向自由落体；时间只由竖直高度决定，落地速度是水平与竖直分速度的合速度。

③ 结构信号：
- "恰好""刚好"→临界状态（如恰好过最高点→绳模型重力提供向心力；恰好不滑动→静摩擦达最大）。
- "至少/至多"→极值或临界条件。
- "匀速"→合力为零；"速度最大"→加速度为零（合力为零的瞬时）。
- "从静止开始"→初速度为零；"回到出发点"→位移为零。
- "求加速度"→先受力分析，再沿运动方向列牛顿第二定律；斜向拉力会改变支持力，进而改变摩擦力。
- "保留几位有效数字/刻度尺读数"→先看仪器分度值与估读规则；最后结果的有效数字不由计算器位数决定。
- "单位换算"→先统一到国际单位制（cm→m、g→kg、mA→A、km/h→m/s），再代公式；量纲不对一定错。
- "U-I 图 / x-t 图 / v-t 图"→先写清横纵轴物理量与单位，再判断斜率、截距、面积的物理意义；图线不过原点常有系统误差或初始条件原因。

④ 术语定义展开：
- "平衡状态"→合力为零（静止或匀速直线运动）。
- "机械能守恒"→只有重力/弹力做功，需先排查其他力做功。
- "弹性碰撞"→动量守恒且动能守恒；"完全非弹性碰撞"→动量守恒、碰后共速。
- "匀变速"→加速度恒定，才能用匀变速公式组。
- "超重/失重"→加速度有竖直分量，与速度方向无关。

⑤ 二级结论/常见引理（逐条标【二级结论】）：
- 匀变速直线运动连续相等时间内位移差 Δx=aT²。
- 匀变速运动中间时刻瞬时速度等于该段平均速度。
- 初速度为零的匀加速运动，连续相等时间位移比 1:3:5:…。
- 绳模型竖直圆周最高点临界速度 v=√(gr)；杆模型临界速度可为零（两者对比是高频陷阱）。

### 教材章节对照提示（辽宁口径：人教版）
- 必修第一册：运动的描述、匀变速直线运动、相互作用（力）、运动和力的关系（牛顿运动定律）。
- 必修第二册：抛体运动、圆周运动、万有引力与宇宙航行、机械能守恒定律。
- 必修第三册：静电场及其应用、电路及其应用、电磁场与电磁波初步。
- 选择性必修第一册：动量守恒定律、机械振动与机械波；第二册：磁场、电磁感应；第三册：分子动理论、气体、热力学定律。

## 化学

### 五类隐含条件排查库

① 数量与条件约束：
- "标准状况"→气体摩尔体积约22.4 L/mol，且对象必须是气体（水、SO₃标况下不是气体，高频陷阱）。
- "常温常压"→不能用22.4 L/mol。
- 化合物中各元素化合价代数和为零；单质中元素化合价为零。
- 溶液电中性：阳离子所带正电荷总数=阴离子所带负电荷总数（电荷守恒）。
- "稀溶液"→密度、比热可近似按水处理（热化学计算）。
- "转化率"→按起始量计算：转化量=起始量×转化率，再用化学计量比换算其他物质（三段式）。
- "密闭容器"→物质的量可直接加减；恒容条件下算浓度还要除以体积。

② 图形隐含性质：
- 溶解度曲线：交点含义、降温结晶方向。
- 能量变化图：反应物与生成物相对高低→吸热/放热。
- 原电池/电解池装置图：电极材料活泼性、离子移动方向、电子流向。
- 滴定曲线：突跃点、半中和点的含义。

③ 结构信号：
- "过量/少量"→产物随用量变化（如CO₂通入石灰水、NaOH与AlCl₃互滴）。
- "逐滴加入"→反应有先后顺序，图像分段。
- "无色溶液"→排除Cu²⁺(蓝)、Fe³⁺(黄)、Fe²⁺(浅绿)、MnO₄⁻(紫红)等有色离子。
- "能大量共存"→逐对排查沉淀、气体、弱电解质、氧化还原、双水解。
- "由水电离出的c(H⁺)"→与溶液总c(H⁺)区分，酸碱抑制、水解促进。
- "晶胞"→先看粒子在顶点/棱/面/体心，按均摊法计数（顶点1/8、棱1/4、面1/2、体心1）；再算配位数与化学式。
- "中心原子杂化方式"→先算价层电子对数（σ键数+孤电子对数），再对应sp/sp²/sp³；空间构型与杂化方式要分开写。
- "价层电子排布"→按构造原理与洪特规则写，注意3d/4s能级交错与例外（Cr、Cu）。

④ 术语定义展开：
- "电解质"→在水溶液或熔融状态下能导电的化合物（单质、混合物都不是）。
- "氧化反应"→化合价升高、失电子；"被氧化"与"氧化剂"方向相反，一字之差。
- "强酸/强碱"→完全电离，写离子方程式时拆；弱酸弱碱不拆。
- "同位素/同素异形体/同分异构体"→对象分别是原子、单质、化合物。

⑤ 二级结论/常见引理（逐条标【二级结论】）：
- 氧化还原"价态归中不交叉"规律。
- 离子放电顺序（惰性电极电解时）。
- "强酸制弱酸""强制弱"的一般规律及其例外（需注明适用条件）。
- 电子守恒、物料守恒、电荷守恒三大守恒在离子浓度比较中的联用。
- 可逆反应平衡量计算用"三段式"：起始量、转化量、平衡量；转化量之比=化学计量数之比。

### 教材章节对照提示（辽宁口径：人教版）
- 必修第一册：物质及其变化（分类、离子反应、氧化还原）、海水中的重要元素（钠、氯）、铁 金属材料、物质结构 元素周期律。
- 必修第二册：化工生产中的重要非金属元素（硫、氮）、化学反应与能量、有机化合物、化学与可持续发展。
- 选择性必修1：化学反应的热效应、化学反应速率与化学平衡、水溶液中的离子反应与平衡；选择性必修2：物质结构与性质；选择性必修3：有机化学基础。
- 课标要求转述示例："认识氧化还原反应的本质是电子的转移""能用电离、离子反应等观念分析溶液中的反应"。措辞不确定标"待核实"。

## 生物

### 五类隐含条件排查库

① 实验与材料约束：
- "哺乳动物成熟红细胞"→无细胞核和众多细胞器（制备细胞膜、无DNA）。
- "紫色洋葱鳞片叶外表皮"→有紫色大液泡，适合质壁分离；内表皮无色需染色。
- 实验设计隐含：单一变量、对照原则、等量原则；"探究"→结果未知需分类讨论，"验证"→结论已知。
- "活细胞"前提：质壁分离、胞质环流、健那绿染线粒体都要求细胞存活。

② 图形隐含性质：
- 细胞分裂图：有无同源染色体、着丝粒排列位置→判定时期（有丝/减数Ⅰ/减数Ⅱ）。
- 代谢途径图：箭头方向、物质进出场所（线粒体不能直接利用葡萄糖）。
- 食物网：营养级与消费者级别差一（初级消费者=第二营养级）。
- 曲线图：起点、拐点、饱和点的生物学含义；光合曲线中"净光合"与"总光合"差一个呼吸量。

③ 结构信号：
- "光照下"→光合与呼吸同时进行；"黑暗中"→只进行呼吸作用。
- "F₁自交""F₁测交"→分离定律/自由组合定律的比例推断。
- "突然停止光照/停止CO₂供应"→C₃、C₅含量变化方向相反，需按来源去路分析。
- "所有/都/一定"→结论范围词，警惕反例（如"所有酶都是蛋白质"错，少数酶是RNA）。
- "自交"≠"自由交配"：自交按各基因型分别计算再按比例相加；自由交配按配子频率计算。
- F₂高茎中 DD:Dd=1:2（不是1:1），只有 Dd 自交才产生矮茎。
- "光照下吸收CO₂"=净光合速率；"黑暗中释放CO₂"=呼吸速率；真正光合=净光合+呼吸（以CO₂计）。
- "假说—演绎"→先观察现象提假说，再演绎推理出可检验预测，最后实验验证；与"类比推理""归纳"区分。
- "预实验"→正式实验前用小样本/少组别摸索条件与剂量，不能替代正式实验的对照与重复。
- "无关变量"→除自变量外可能影响因变量的因素；要写清"哪些量相同、怎么保持相同"，不能只写"控制变量"。

④ 术语定义展开：
- "质壁分离"→活细胞+大液泡+外界溶液浓度>细胞液浓度，三条件缺一不可。
- "稳态"→理化性质和化学成分的动态平衡，不是恒定不变。
- "基因表达"→转录+翻译两个阶段。
- "相对性状"→同种生物同一性状的不同表现类型。
- "种群"→一定区域同种生物全部个体（"全部"是关键词）。

⑤ 二级结论/常见引理（逐条标【二级结论】）：
- 肽键数=氨基酸数−肽链数；至少含游离氨基/羧基数=肽链数。
- 双杂合自交9:3:3:1的常见变式（9:7、9:6:1、15:1等）及对应基因互作类型。
- DNA半保留复制：n次复制后含母链的DNA分子恒为2个。
- 能量传递效率10%~20%按营养级间同化量计算，"至少消耗"按20%、"最多消耗"按10%。

### 教材章节对照提示（辽宁口径：人教版）
- 必修1《分子与细胞》：走近细胞、组成细胞的分子、细胞的基本结构、细胞的物质输入和输出、细胞的能量供应和利用（酶、ATP、呼吸、光合）、细胞的生命历程。
- 必修2《遗传与进化》：遗传因子的发现、基因和染色体的关系、基因的本质、基因的表达、基因突变及其他变异、生物的进化。
- 选择性必修1《稳态与调节》：内环境与稳态、神经调节、体液调节、免疫调节、植物生命活动调节；选择性必修2《生物与环境》：种群、群落、生态系统；选择性必修3《生物技术与工程》。
- 课标要求转述示例："说明细胞通过分裂实现增殖""阐明有性生殖中基因的分离和自由组合使子代基因型出现多种可能"。措辞不确定标"待核实"。
