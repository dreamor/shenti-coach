# 辽宁地区高中教材章节对照表

## 〇、考纲与教材映射口径（先读）

- **考纲口径**：指《普通高中课程标准（2017 年版 2020 年修订）》的内容要求，以及中国高考评价体系（“一核四层四翼”）的考查要求。多数省份已不再单独发布考试大纲，**禁止编造“考纲条目编号”**。
- **三层写法**：每个条件的“考纲与教材对应”列写全三层：①课标要求（准确转述内容要求）；②教材章节（版本 + 册次 + 章名，能定位到节就写节）；③知识点具体内容（定义、定理、公式、定律的准确表述）。
- **版本口径**：辽宁默认数学人教 B 版，物理/化学/生物人教版；用户明确说明其他版本时以用户为准。用户未说明地区时按辽宁口径并注明“（按辽宁常用版本标注，版本不同请指出）”。
- **定位规则**：优先查本文件的章节表；表里没有或不确定时，只写版本 + 册次 + 主题，并标“节次待核实”；禁止编造节号、页码、课标条文编号。
- **跨章节综合题**：列出所有相关章节，并标注主要考查章节。
- **二级结论**：教材没有直接给出的，在对应列注明“教材无直接结论，属拓展结论，解答题需论证”。

适用范围：辽宁"3+1+2"新高考；数学不分文理。默认版本：**数学人教B版，物理、化学、生物人教版**。用户明确说明学校使用其他版本时，以用户版本为准，并在输出中注明。

使用规则：
- 先查本表定位章节，再写"版本 + 册次 + 章名"；表里没有或不确定的，只写"版本 + 册次 + 主题"，标"节次待核实"。
- 禁止编造节号、页码、课标条文编号；禁止引用已废止的"考试大纲条目"。
- 教材章节只是定位，具体知识表述以课标转述 + 教材内容为准；不确定标"待核实"。
