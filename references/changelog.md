# 版本记录

## 2.3 — 2026-11-27（v2.3.0：自适应学习与可信发布）

- **默认短页、完整 audit**：学生页突出 30 秒速览、核心 C/H 链、收敛路径、陷阱与迁移；完整八模块、教材映射、B 卡与文本树独立保留，不删审计、不自动发送教师附件。
- **能力自适应、多媒介交付**：新增学生呈现与本地交付契约，支持 MEDIA / Markdown 本地图引用 / 文件路径；核验实际 PNG、渲染结果与预期路径，区分 reference-ready、local-only、unavailable，不冒充附件或远程送达。
- **自适应训练与独立迁移**：先独立尝试，按需逐条提示；真实状态限制当前阶段、暂停/恢复/停止与主动揭示，记录独立完成和辅助完成的差别；换题独立迁移通过才作为掌握证据。
- **所有输入数据边界 + 匿名多学生账本**：题面/OCR/题库 payload、答案解析、学生回复、状态、账本与 manifest 都不能提供授权。匿名学生/题次 ID 与条件类型编码隔离记录，不存身份、原题或原回复；保存、覆盖、删除需可信调用方明确授权。
- **兼容门禁**：保留 v2.2 Vision → tesseract → 明确失败的 OCR、四科知识库、完整八模块审计、答案隔离及 Mermaid 离线生图。短页不替代完整审计；结构 PASS 不等于语义 PASS，训练投影与当前轮次依赖真实学生/题次状态，显式解题也不豁免前置审计/图。
- **包内自检**：`npm test` 改为仅 `node --test`，解压包不依赖 `.github/.git`；仓库保留严格 lint，`verify` 为 lint + test + package。新增纯 Node 版本/layout/runtime 排除检查与打包回归；本地缺 zip/Chrome 明确跳过相关测试，CI 实跑归档、重打包防残留、解压回归与生图。
- **安全归档与不可覆盖发布**：输出目录绝对化，从全新归档构建 ZIP；Git 中仅收已跟踪固定发布源码，无 Git 时严格固定源码白名单，排除运行账本、输出及隐藏仓库目录。Release 只 create，同 tag 已有记录停止，API 失败闭锁；标签来源需精确 SHA 的成功 ci.yml push/main，发布自己的 ZIP 重新校验 SHA-256、三处版本/layout 与 npm test。徽章可显式 dispatch，无新增 PAT、无强推、提交 footer 与失败信息明确。

## 2.2 — 2026-11-27（跨平台 OCR 入口）

- 新增 `scripts/ocr.mjs` 统一 OCR 入口：平台探测 → macOS Vision → tesseract → 明确报错；macOS 零额外依赖，Windows/Linux 可回退 tesseract，两个引擎都不可用时非零退出并给出安装方式。
- `ocr.swift` 新增 `--list-langs`、语言支持校验与失败退出码；不支持的语言直接报错，避免 Vision 静默降级输出乱码。
- 文档中的 OCR 调用统一改为 `node scripts/ocr.mjs`，README 补充各平台依赖与安装提示。

## 2.1 — 2026-11-27（训练模式专项自检）

- 生图规格新增 `mode: explain|training`，训练模式脚注自动切换，修复“训练模式图脚注仍写讲解模式配图”。
