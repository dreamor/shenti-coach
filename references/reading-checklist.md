# 读题拆解与自检清单

本文件是 shenti-coach 的内部执行清单。输出八模块前必须按这里过一遍；只把结果写进八模块，不把检查过程原样贴给学生。

## 一、五步读题法

0. **判题型**：先判主题型（选择/填空/解答/计算/实验/证明）和副题型；按 `references/question-type-playbooks.md` 选用专项检查。
1. **通读圈词**：圈出数字、单位、范围词（至少/至多/恰好/不超过）、否定词（不/无/非）、状态词（静止/匀速/缓慢/标准状况/无色/透明）、比较词（增大/减小/升高/降低）。
2. **定目标**：几问？每问求什么？把"求什么"写成目标条件（Q1、Q2……），目标本身也是条件。
3. **列显性**：逐句编号 C1、C2……；一句话含多个条件要拆开；图形/表格条件单列 G1、G2……；统一单位。
4. **扫隐含**：按学科五类库逐类排查，写 H1、H2……；每条必须注明"由 C几/G几的哪个词触发"。
5. **建关系**：条件→结论→路径；标核心/备用/干扰；检查闭环——每个目标都有路径，每个隐含都有来源。

## 二、通用检查项

1. 题目是否完整复述，公式、数字、单位与题面一致？
2. 目标是否全部列出（多问逐一编号）？
3. 每个显性条件是否有编号和题面触发词？
4. 图形、表格、实验装置条件是否单列（G 编号）？
5. 每个隐含条件是否都有来源编号？
6. 定义域、取值范围、端点开闭是否检查？
7. 单位是否统一，物理量是否带单位？
8. "至少/至多/恰好/不超过"等范围词是否处理？
9. 是否需要分类讨论？分类是否不重不漏？
10. 守恒量（电荷/质量/能量/物料/概率）是否检查？
11. 教材章节是否按辽宁口径，未核实处是否标"待核实"？
12. 文本树、图片、条件表中是否没有最终答案？
13. 填空题是否**一空一 B**（B 号数量 = 题面空位数），且只写判断依据、没写待填词？
14. 多问题目的每个 Qn 是否只用了第 n 问之前或同阶段的已知？有没有把后续步骤的产物当成前一步的答案？
15. 题库带官方解析时，是否建过"B 号 → 答案指纹"表，并用指纹反查过 `〇`–`六`？
16. 实验题是否写清自变量、因变量、控制变量、对照、等量、重复、数据、误差、安全？
17. 计算题是否列了已知量—符号—单位，做了量纲/范围回检？
18. 缺失公式、装置图、表格、单位时，是否标了 G0 并停止脑补？
19. 输出开头是否有"30 秒速览"（问什么 / 关键触发词 / 最大陷阱），且没有写答案？
20. 空位 ≥2 时是否有表格化"空白作答卡"（空号 | 小问 | 待填类型 | 判断依据），一空一行？
21. 多问流程/实验题是否有"阶段 | 已有物料 | 尚无物料 | 对应小问"阶段表，Qn 未使用后续产物？
22. 答案指纹是否做过"题干减法 + 同义扩展"检查，而不是只查官方答案原句？
23. 表格是否过宽/单元格过长；知识列是否写成了可直接抄写的答案句？
24. 作答点是否覆盖“显式下划线空 + 隐含作答点（作图/说明/求/证明/写出）”？`answer_slots` 与 B 号是否一致？
25. 题内嵌选项是否建了“小问—选项范围—空位”归属表？一个空填字母组合时是否只编一个 B？
26. 无下划线作图题是否也编了 B 号？作图三要素（坐标轴/关键点/图线方向）是否写清？
27. 工艺流程题是否有阶段表？滤渣是否按“不溶杂质 + 本段不溶产物 + 未反应固体”三来源核对？
28. 排序/因果题是否确认第 1 环为“直接作用”、选项是否默认不重复？小问编号是否按“句首/换行/标点后且递增”识别？

## 三、分学科附加检查

### 数学
- 定义域：分母≠0、偶次根式≥0、对数真数>0、实际问题变量范围。
- 二次函数：二次项系数是否为 0、开口方向、对称轴、判别式使用条件（恒成立 vs 有解）。
- 区间：端点开闭、单调区间是否包含于定义域。
- 结构词："恒成立"→最值/分离参数；"存在"→值域交集；"任意"→全称条件。
- 参数：是否需要按参数与区间的位置分类；解出后是否回代检验。

### 物理
- 研究对象与系统：单个物体、连接体、整体法/隔离法。
- 受力：重力、支持力、摩擦力、拉力、场力；斜向力是否改变支持力。
- 方向与符号：规定正方向；矢量分解后各分量方向。
- 状态：静止、匀速、匀变速、临界（恰好/最大静摩擦/恰好过最高点）。
- 守恒：机械能守恒条件、动量守恒条件、能量转化路径。
- 单位：结果是否带单位，单位是否统一到国际单位制。

### 化学
- 状态：气/液/固；标准状况只适用于气体（SO₃、水、乙醇等除外）。
- 条件：温度、压强、浓度、催化剂；"恒容/恒压"影响计算。
- 量：物质的量、质量、体积、浓度；单位与换算。
- 过量/少量：产物随用量变化；"逐滴加入"有先后顺序。
- 可逆反应：转化率、平衡量、三段式；转化率分母是起始量。
- 守恒：电荷守恒、物料守恒、电子守恒。
- 离子共存：无色（颜色）、透明（沉淀）、大量（反应）三条件分开查。

### 生物
- 材料：哺乳动物成熟红细胞（无核）、洋葱表皮（液泡）、活细胞前提。
- 条件：光照/黑暗、温度、CO₂ 浓度；"光照下吸收"=净光合，"黑暗释放"=呼吸。
- 世代与比例：F1/F2、自交/自由交配、测交；F2 高茎中 DD:Dd=1:2。
- 概率：每个比例来自哪类个体、是否加权。
- 实验：单一变量、对照、等量、重复；"探究"需分类讨论，"验证"结论已知。
- 术语：相对性状、种群、稳态、基因表达。

## 四、题型专项检查

### 选择题
- 选项是否逐项判断，而非只判断一个？
- 多选题是否说明组合关系？
- 讲解模式是否没有报正确选项？
- H1 是否具体到本题的题干专题或选项级策略，而不是只剩“逐项验证”？
- 30 秒速览是否写出“问什么对象”，没有 `选出：则`、裸“正确的一项”、无对象的“所给说法”？
- 四个选项的验证角度是否逐项区分，并落到该项的关键系数/角度/符号/图像？

### 填空题
- 每空是否有 B 编号和待填类型？
- B 号数量是否等于题面空位数？有没有把两个空合并成一个 B？
- 是否区分数值/方向/名称/化学式/操作/原因/是否/标号？
- 多空依赖是否只写“Bn 依赖 Bm”，没有代入答案？
- 空外单位、有效数字、正负号是否检查？

### 解答题
- Q1、Q2 是否分别有目标和闭环路径？
- Q1 结论是否只以“所得关系”出现，没有写成 Q2 的已知数值？
- 每问是否只用了该问之前或同阶段的已知，没有拿后续步骤的产物回答前一步？
- 证明题是否每步有依据？

### 计算题
- 已知量、符号、单位是否齐全？
- 物理正方向、化学限量试剂、生物比例来源是否写清？
- 是否检查量纲、数量级、范围、端点？

### 实验题
- 目的是否具体？
- 自变量/因变量/控制变量是否具体到“控什么、怎么控”？
- 对照、等量、重复是否落实？
- 图形/表格数据是否有 G 编号与单位？
- 误差来源与改进措施是否一一对应？

### 工艺流程题
- 是否建了“阶段 | 进料 | 出料 | 尚无 | 小问”阶段表？
- 每问是否只用了本阶段及以前的物料？
- 滤渣是否按三来源逐条核对，没漏“过量未反应固体”？
- pH 范围是否写了双侧边界而不是单点？
- 循环物质是否真的能回到前段且不引入新杂质？

### 题内嵌选项 / 图像选项
- 选项是否只归到对应小问，没有当整题 A–D？
- 组合答案是否只编一个 B？
- 每个选项图是否单列 G 号，条件表是否写“由图读出”？

### 作图题
- 是否有 `answer_slots` 级别的 B 号，而不是只数下划线？
- 坐标轴、单位、标度、关键点、图线方向是否齐全？
- 是否没有把图线形状结论写进条件表？

### 排序 / 因果链
- 第 1 环是否与题干起点直接相连？
- 是否明确选项不重复（或题面允许重复）？
- 每个空是否只写本步判据？

### 公式/图形缺失
- 是否列 G0 缺失项？
- 是否只拆已有条件？
- 依赖缺失项的空是否标“待核实”？

## 五、常见误读词表

| 词 | 易错读法 | 正确读法 |
| --- | --- | --- |
| 至少/至多 | 当成精确值 | 极值或临界条件 |
| 恰好/刚好 | 普通状态 | 临界状态，常对应等号 |
| 缓慢 | 速度小 | 准静态，每一时刻近似平衡 |
| 无色 | 透明 | 排除有色离子，不等于透明 |
| 透明 | 无色 | 只表示无沉淀/浑浊，可能有颜色 |
| 标准状况 | 任何物质都能用 22.4 L/mol | 只适用于气体 |
| 纯合 | 显性 | 两个等位基因相同（DD 或 dd） |
| 自交 | 自由交配 | 同一个体或同基因型群体交配 |
| 吸收 CO₂ | 真正光合 | 净光合（已扣除呼吸） |
| 释放 CO₂ | 光合 | 呼吸（黑暗下只测呼吸） |
| 恒成立 | 有解 | 对区间内所有值都成立，常转最值 |
| 存在 | 恒成立 | 区间内至少一个值成立，常转值域交集 |
| 任意 | 存在 | 全称条件，注意反例 |

## 六、典型反例

| 学科 | 坏拆解 | 好拆解 |
| --- | --- | --- |
| 数学 | 根号下式子"大于 0" | 根号有意义是"≥0"；定义域为 R 时用 Δ≤0，不是 Δ<0 |
| 物理 | 斜向下推力仍写 N=mg | 斜向下推力使 N=mg+Fsinθ，摩擦力随之增大 |
| 化学 | 标准状况 22.4 L SO₃ 当作 1 mol | 标准状况下 SO₃ 不是气体，不能用气体摩尔体积 |
| 生物 | 1000 个碱基对直接当 1000 个碱基 | 1000 个碱基对=2000 个碱基；A=T、G=C |
| 填空题 | 隐含条件表写“B1 是 CO₂ 固定” | 只写“B1 由 C5 与 CO₂ 生成 C3 判断碳的转移方向” |
| 实验题 | 只写“控制变量” | 写清“各组初始体积、浓度、温度相同” |
| 多问题目 | 把 Q1 算出的值直接写进 Q2 条件 | 只写“由 Q1 所得关系”，保留未知占位 |

## 七、交付前自检（逐条打勾）

- [ ] 〇 复述完整，公式、数字、单位与题面一致
- [ ] 一 目标全部列出，多问逐一编号
- [ ] 二 显性条件编号完整，触发词来自题面
- [ ] 三 隐含条件有来源编号，五类库逐类排查过
- [ ] 四 文本树与图片节点、连线、触发词、相关度一致
- [ ] 五 收敛为 1~2 条路径，不代入计算、不给结果
- [ ] 六 陷阱提醒具体到"一字之差"
- [ ] 七 审题收获可迁移
- [ ] 图形/表格条件已单列 G 编号
- [ ] 需要分类讨论的题已写分类标准并检验
- [ ] 教材按辽宁口径，未核实处标"待核实"
- [ ] 全图、全表、全文无最终答案（解题模式仅解答部分除外）
- [ ] 题型专项检查已执行
- [ ] 填空题 B 编号完整、无待填词泄露
- [ ] 填空题一空一 B，B 号数量与题面空位数一致
- [ ] 多问题目未把后续步骤产物当成前一步答案
- [ ] 题库带解析时已完成“B 号 → 答案指纹”反查
- [ ] 实验题变量/对照/等量/重复/误差/安全齐全
- [ ] 缺失公式或图形已标 G0，未脑补
- [ ] 开头有 30 秒速览，未写答案
- [ ] 空位 ≥2 时使用表格化空白作答卡，一空一行
- [ ] 多问流程/实验题有阶段边界表，Qn 未用后续产物
- [ ] 答案指纹做过题干减法与同义扩展
- [ ] 表格不过宽，知识列没有答案句
- [ ] 作答点已按 answer_slots 核过，隐含作图/说明点也编了 B
- [ ] 题内嵌选项有归属表，组合答案只编一个 B
- [ ] 工艺流程题有阶段表，滤渣三来源齐全
- [ ] 排序题第 1 环是直接作用，选项未重复
- [ ] 小问编号已排除引用、价态并检查递增；带编号小问内嵌的 ①②③ / a. b. 子任务已判断是否作答点（条件/选项引用不误拆）
- [ ] 小问编号已排除数学公式内部的 `(1)(2)`（`$f(1)$`、`$P(2<X)$`）与函数记号；子问正文不是 `= $`/`$\"的` 这类残句
- [ ] 二、显性条件表没有混入设问：无 `____`/`【空】`，无“请/试/回答/写出/作出/建立”开头的整句，无 A–D 选项整行
- [ ] 题干里的表格已按原表逐行保留（T1–T4 不折叠成一行），并标了行列标题与单位
- [ ] 隐含条件只写本题专项；通用模板（逐项验证、因果链、单位）放在第七部分，不占 H 号
- [ ] 选择题没有硬套学科专项隐含条件；最大陷阱来自“选项互斥/否定问法”，不是填空风险标签
- [ ] 选择题 H1 是具体规则（题干专题或选项级策略）；“逐项验证”只作无具体规则时的兜底，不占 H 号
- [ ] 30 秒速览写到了具体对象；无 `选出：则`、裸“正确的一项”、无对象的“所给说法/判断/结论”
- [ ] 四个选项的验证角度有区分，公式选项未截成统一的“…”，纯图选项标了“对照 G 清单”
- [ ] C 表没有把 `$|x|$` 的绝对值竖线误当表格分隔符；纯填空 C1 写“题干给定对象”，不抄空位
- [ ] 空白卡 clue 不是 `①和（作答点）`、`②；`、`/【空】` 这类残句；已补小问/原表行上下文
- [ ] ①②③ 若只是条件/选项/性质引用，没有误拆成多个 B；只有带作答动词/落点/空位的子任务才逐个编 B
- [ ] 多问题目目标分析是三列表，且"问什么"是任务骨架、不是小问原文截断；"从哪类条件入手"引用了 C/G/H（或明确写"本问动词+题干条件"）
- [ ] 3 问以上或节点超过 20 个时，大爆炸图已按 Q 分组，连线为 ROOT→Qn→C/H/B/G，不是所有节点从 ROOT 放射
- [ ] `check_output` 只报结构 PASS 时，交付说明写了"语义待复核"；人工复核后才声明语义 done
