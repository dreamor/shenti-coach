# 题型识别与专项打法

本文件是 shenti-coach 的题型执行层。讲解模式及解题前置讲解的八模块框架不变；先识别题型，再把专项检查写进对应模块，不新增第九模块。训练模式只输出当前阶段。下文的不泄题规则适用于八模块讲解区、训练回复与图；用户明确要求解题时，仅独立“完整解答”区允许答案、选项判定与完整推导，不豁免前置讲解。

## 0. 题型识别表

| 题型 | 识别信号 | 主要风险 | 专项动作 |
| --- | --- | --- | --- |
| 选择题 | A/B/C/D、多选、选出正确/错误项 | 把正确选项当条件；逐项理由不完整 | 选项逐项判断表；讲解模式不报正确项 |
| 填空题 | 下划线、横线、括号、“填______” | 隐含条件表直接写成待填答案 | 每个空编 B1/B2；只写判断依据，不写待填词 |
| 解答题 | “求…”“证明…”“回答下列问题”、多小问 | Q1 结果被当成已知条件；分问路径不闭环 | Q1/Q2 分问目标；Q1 结果用“所得关系”占位 |
| 计算题 | 求数值、比值、功率、浓度、产率、速率 | 单位、方向、有效数字、限量试剂 | 已知量—符号—单位表；量纲与范围回检 |
| 实验题 | 器材、步骤、装置图、数据表、误差、对照 | 变量/对照/等量/重复缺失；空白答案外泄 | 实验专项卡；G 编号图形条件；B 编号空白 |
| 证明题 | “证明”“求证”“判断并说明理由” | 把结论当条件；链条断裂 | 已知→已证→目标链条；每步写依据 |
| 图像/表格题 | 图1、表1、坐标轴、图线 | 自造图形条件；漏单位/图例 | 图和表都编 G 号（G1 表1）；写“由图/表读出”；缺失时标 G0 |
| 工艺流程题 | 流程框图、原料→反应→分离→产品、滤渣/滤液/母液、循环利用 | 阶段错位；把后续产物当前步答案；滤渣漏“未反应固体” | 建阶段表；每问只答本段；滤渣三来源 |
| 题内嵌选项 | 非选择题某一小问后出现 A–D/A–C | 把局部选项当整题四选一；一个空填组合却拆成多个 B | 建“小问—选项范围—空位”归属表；组合只编一个 B |
| 图像选项 | 选项本身是图/表/曲线 | 只看文字不看图；漏“由图读出” | 每个选项图单列 G；按斜率/截距/交点/面积逐项验证 |
| 作图题 | “画出”“描点作图”“作出图像”“补全电路图”，可能没有下划线 | 只数下划线漏作答点；图线结论写进条件表 | 用 answer_slots 计作答点；作图三要素：轴/点/线 |
| 排序/匹配题 | “按…顺序”“用字母和箭头表示”“先后顺序” | 第 1 环不是直接作用；重复使用选项 | 先写每项直接作用对象；4 空 4 选项默认不重复 |
| 判断并说明 | “判断…并说明理由”“是否合理” | 判断与理由混写；理由里重复结论 | 判断空与理由空分开；理由只写依据 |
| 计算+说明 | 先算后解释、说明原因/意义 | 说明里写出最终数值；只算不解释 | 先算（中间量可写）再写说明角度；说明只给要点 |

题型可以叠加。例如“实验题+计算题”同时执行实验专项和计算专项；主题型写在前，副题型写在后。

## 1. 选择题

1. 题干条件仍用 C 编号，选项用 A–D 原标号，不另造 O1。
2. 讲解模式逐项写“该项触发什么知识点 / 需要验证什么 / 常见误判点”，**不写“符合/不符合”的判定结论**；逐项报符合/不符合等于变相报答案。解题模式的独立完整解答区才逐项判定“符合/不符合 + 理由 + 触发词”，多选题再补“组合关系”。
3. 讲解模式不写“正确选项是 X”，也不写“排除 A、C、D”这类等价结论；只给验证方向。解题模式的独立完整解答区才给选项。
4. 选项本身含公式时，先规范抄写选项，不允许只写“第一个选项”。
5. 若选项是“以上都对/至少两个正确”，把它当组合条件，不能逐项孤立判断。
6. **H 表第一条必须是具体策略。** 优先题干专题（核反应守恒、函数定义域、离子共存、遗传比例等），其次选项级策略（单位/守恒/端点/绝对化/图像/因果方向）。“逐项验证”只是没有任何具体规则时的兜底，不占 H 号；已有具体 H 时只放第七部分。
7. **30 秒速览写到对象。** 禁止 `选出：则（ ）`、裸“正确的一项/不合理的一项”、无对象的“所给说法/结论”。题干引号内对象优先，其次知识点名；结构词只做最后兜底。
8. **四个选项的验证角度必须可区分。** 同类规则命中四项时补“本项核对：<该项系数/角度/符号/短证据>”；公式不得截成统一“…”，纯图选项写“对照 G 清单中的对应图”。

## 2. 填空题

1. **一空一 B**：先数题面下划线/横线/括号中的空位，每个空编号 B1、B2……；一题多空时用 Q1-B1、Q2-B1，或顺序 B1…Bn 并附"空号—小问—待填类型"映射表。不得把"两个指标/两个变化/两个环境因子"合并成一个 B；"答出 2 点即可"算 1 个空，但作答要点要覆盖 2 点。
2. 在目标分析中写清每空要填什么类型：数值/符号/方向/名称/化学式/方程式/操作/原因/是否/标号。
3. 隐含条件表只写“由哪个条件、按什么知识判断 Bn”，不写待填词本身。
4. 多空之间存在依赖时，写“B2 依赖 B1 的判断结果”，不要把 B1 的答案代入 B2。
5. 空外已有单位时，结果只填数值；空外无单位时，提醒单位写在空内。有效数字和正负号另列检查。
6. 填“名称”不写化学式，填“化学式”不写名称，填“标号”不写内容，填“操作”不写现象。
7. 开放空（原因/结论/改进措施/优点）只给作答方向与必须覆盖的要点，不给成句答案，也不把答案名词直接写进条件表/文本树/图片。

   反例（泄题）：题目问"碳通过什么作用返回大气"，条件表写"碳通过呼吸作用返回大气"。
   正例（只给方向）：写"B1：从'有机物分解、释放CO₂'的生理过程角度作答，需覆盖'分解有机物'这一要点"。

   自检三问：①这句话是否包含待填词/答案名词？②是否把因果链写全？③是否只给了判断依据与要点？失败条件是 **①是或②是或③否**；只有①否、②否、③是才通过，否则改写。

8. **多问阶段边界**：Qn 只能用第 n 问之前或同阶段的已知，不得把后续步骤的产物当成前一步的答案。典型反例：题目问"滤液1 中铜的存在形式"，却拿"部分蒸氨后生成 CuS"作答；正确做法是回到"滤液1"这一股物料，用已知②中蒸氨前后的变化反推。
9. **官方解析核对**：题库带 solution/analysis 时，先建"B 号 → 官方答案指纹"表，核对空数与答案；再把指纹在 `〇`–`七` 中搜索，命中即改写为角度/判据提示。答案指纹不要用单个高频词（如"温度"），要用最短可识别词组（如"Fe(OH)₃胶体""黑暗条件"）。
10. **空白作答卡**：空位 ≥2 时，必须先写"空号 | 小问 | 待填类型 | 判断依据（不写答案）"四列表；一空一行。没有这张表，不允许直接进入隐含条件表或路径提示。
11. **同义扩展检查**：答案指纹只查原句会漏"同义泄题"。例如官方答案是"增大氧气溶解度"，还要检查"溶解与供给""O₂ 的溶解""提高浓度"等变体；命中就改写为"先判断加压改变了什么物理量"。
12. **多问题目的阶段表**：流程/实验/多材料题在目标分析后列"阶段 | 已有物料 | 尚无物料 | 对应小问"；写 Qn 前先核对阶段，避免拿后续产物回答前一步。

反例：题目问“反应①是______过程”，隐含条件表写“反应①是 CO₂ 固定”。这已经把 B1 答案泄露。应写“B1：由 C5 与 CO₂ 生成 C3 判断碳的转移方向”。

## 3. 解答题

1. 多问逐一列 Q1、Q2……；每问都要有独立目标和闭环路径。
2. 共用条件表，但目标表分问；某条件只服务某一问时标“Q2 核心”。
3. Q1 的结论在 Q2 中只能写成“由 Q1 所得关系”，不得写出具体值、区间或式子结果。
4. 证明题把目标写成“证明……”，路径写成“已知→中间结论→目标”，每步注明定理或定义。
5. 解答题中的二级结论必须提示“解答题需先证明”；不能把二级结论直接当已知。

## 4. 计算题

1. 先列“已知量—符号—数值—单位”与“待求量—符号—单位”，再选公式。
2. 物理：规定正方向；矢量写方向；区分状态量与过程量；检查 g 取值、单位制、有效数字。
3. 化学：先判断过量/少量与反应顺序；写单位 mol、g、L、mol·L⁻¹；产率按限量试剂算理论量。
4. 生物：概率/比例写来源与加权；能量传递效率按营养级同化量；光合/呼吸分清总净。
5. 中间式子可以写，但不得算出最终结果；若必须用中间数值才能说明路径，标注“中间量，非最终答案”。
6. 结果回检：量纲、数量级、范围、端点、正负、是否满足题设状态。

## 5. 实验题

实验题必须先过 `references/experiment-checklist.md`，再把结果写进八模块。

1. 目标：实验目的是“测什么/探究什么/验证什么/制备什么”。
2. 原理：对应定律、反应、公式或生物机制；写明自变量、因变量、控制变量。
3. 器材：器材图/装置图单列 G1、G2……；缺失时写 G0“题面图未提供，待确认”，不得脑补。
4. 步骤：按“准备—操作—读数—重复”顺序；空白步骤编 B 号。
5. 数据：表格写行列含义、单位、有效数字；图像写横纵轴、斜率/截距/面积含义。
6. 误差：系统误差/偶然误差、来源、减小方法；不要只写“减小误差”。
7. 安全与规范：尾气、防倒吸、防氧化、防水、防暴沸、电表量程、平衡摩擦等按学科检查。
8. 不泄题：实验结论、待填仪器名、待填操作、待填现象均不得写进条件表或大爆炸图。

## 5.1 工艺流程题（process_flow）

识别信号：流程框图、原料→反应→分离→产品、滤渣/滤液/母液、pH 调控、循环利用。全库 103 题，是当前最大缺口。

1. **先建阶段表**（复用 §2.12）：`阶段 | 进料 | 出料/产物 | 这一阶段还没有什么 | 对应小问`。写 Qn 前先定位它落在哪一行。
2. **每问只答本段**：问“滤液1 中…”就只能用本段及以前出现的物料；后一步才生成的沉淀、后一步才加入的试剂，一律不得提前写进前一步答案。
3. **滤渣三来源**：①原料中不溶的杂质；②本段反应生成的不溶物；③过量未反应的固体。三条逐条过，漏“未反应”是最常见失分点。
4. **pH 调控**：写“使某离子开始沉淀/完全沉淀”的两侧边界，回答“范围”而不是单点；“完全沉淀”通常按残留浓度 ≤1×10⁻⁵ mol/L 理解，题面另有规定时以题面为准。
5. **循环物质**：看箭头“回到哪一步”，只选能从该步进料重新进入、且不引入新杂质的物质；只在后段出现、前段不用的不算。
6. **方程式/离子方程式**：先写清反应物来自哪股物料，再配平电荷与原子；官方答案与设问口径冲突（如设问问离子方程式、官方写化学式）时标“待核实口径”，不硬凑。
7. **产率/纯度**：先定限量试剂与目标产物的理论量；区分“已转化”与“未反应”，注意样品称量形态是否含结晶水/杂质。
8. 讲解模式下，阶段表与滤渣三来源只写“查什么”，不写具体物质名。

## 5.2 题内嵌选项与图像选项（embedded_options / image_option）

识别信号：非选择题某一小问后出现 A–D/A–C；`options` 非空但整题不是选择题；选项本身是图、表、曲线。全库 9 + 24 题。

1. **建归属表**：`小问 | 选项范围 | 选项数 | 作答空位`；选项只归到该小问，不得当整题四选一。
2. **一个空填字母组合**（如“选 A、C”）只编 **一个 B**；不得把 A–D 拆成四个 B。若题面是“多选”，按多选处理；若只是“填字母”，按一个空处理。
3. **图像选项**：把每个选项图当独立图形条件 G1…G4，条件表写“由图 G2 的斜率正负/截距/交点/拐点/面积读出…”，不得只看选项文字。
4. 讲解模式不写“选 X”，只写每一项要验证的图线特征与常见误判（如“先由题干关系判断斜率符号，再与 G2 的图线变化方向对照，注意横纵轴顺序”）；不得提前给出应有的正负斜率或“不符合”的判定。用户明确要求解题时，仅在独立完整解答区给出逐项判定与理由。
5. G 编号全题统一：题干图与选项图连续编号，禁止两个 G1。
6. 选项图缺失或与题面图数不符时，标 G0，不脑补图形。

## 5.3 作图题与无下划线作答点（drawing / answer_slots）

识别信号：“在图中画出”“描点作图”“作出…图像”“画出受力示意图”“补全电路图”“在坐标纸上…”。全库 14 题作图题，另有约 263 个隐含作答点。

1. **作答点 = 显式下划线空 + 隐含作答点**（作图/说明/解释/求/证明/写出）。预检看 `answer_slots`；结构闸门用 `--answer-slots N`，不要只传 `--blanks`。
2. 每个作答点仍编 B 号；作图题 Bn 的“待填类型”写“图线/示意图/连线/标注/辅助线”，不是“数值”。
3. **作图三要素**：坐标轴（物理量 + 单位 + 标度）、关键点（截距/交点/极值/起点）、图线或箭头方向；路径提示写“由斜率/面积求…”。
4. 不得把图线形状结论写进条件表（如“是一条过原点的直线”若正是要画的结论，只能写“判断图线是否过原点”）。
5. 题面要求“保留作图痕迹”时，提醒写清辅助线、垂足、交点、标度。
6. 只有文字说明、没有下划线的问，也要单独编 B（如“请说明理由”），否则答案隔离会漏。

## 5.4 排序/因果链题（sorting_matching）

识别信号：“按…顺序排列”“用字母和箭头表示”“先后顺序”“因果链条”“匹配”。全库 3 题排序 + 少量匹配。

1. 先列每个选项的“触发条件/直接作用对象”，再排序；不要凭语感。
2. **第 1 环必须与题干起点直接相连**：问“某措施的直接作用”，第 1 环就不能从更远的结果（如土壤肥力）起手。
3. n 个空排 n 个不同选项时，明确“不重复使用”；题面写“可重复”才允许重复。
4. 每个空只写“这一步的判据”，不写完整因果链结论。
5. 匹配题建 `左项 | 右项 | 匹配依据` 表：先定唯一匹配项，再用排除法，最后回读是否一对多。

## 5.5 判断并说明 / 计算+说明（judgment / calc_plus_explain）

1. **判断与理由分开**：判断空只写“是/否/偏大/偏小”的判据；理由空写“依据哪个定律/哪组数据/哪个守恒关系”。
2. 理由里不得出现判断结论的同义句，也不得出现答案数值；官方答案把判断与理由写在一句时，拆成两个 B 核对，不得合并。
3. **计算+说明**：先算（中间量可写，最终值不写），再写说明角度；说明空只给必须覆盖的要点（误差来源/守恒关系/因果机制/实际意义）。
4. 说明空禁止把计算结果再抄一遍，也禁止用“所以…”把结论写全。

## 5.6 小问编号识别（所有题型通用）

1. 小问编号必须满足：位于**句首/换行/句末标点之后**，且按 1,2,3… **递增**；“回答（1）～（4）题”“见（1）中”这类引用不算小问。
2. 化学价态“(Ⅱ)”、罗马数字、年份括号、浓度单位括号都不是小问。
3. 小问编号之前若出现下划线/作答点，归入 **Q1 的前置空位**，在空白卡里注明“前置”，不得报“未归类”。
4. 编号不连续（只有 (1)(3)）时先核对原卷，可能是 OCR 丢号；标“待核实”，不擅自补 Q2。
5. 题干只有“回答下列问题”而无编号、但有多个问号时，按问号/分号拆问；拆完回读，确认没有改变题意。
6. **小问内再嵌 ①②③ / a. b.**：先看这些标记是否在句首/换行/句末标点后，再看正文是否带“求/说明/写出/判断/画/补全”等作答动词。带作答动词的每个子任务单独编 B；只在“条件①”“选项 a.”“性质②”里出现的标记不拆。一个 `（2）` 里含 ①方程式、②原因、③补全装置时，应编 B2–B4，而不是只编 B2。
   - **判定口径（2026-11-27 全量修正）**：至少两个片段自带作答动词、作答落点（…式/…值/…原因/…结论）或空位时，才按子任务拆；否则整段算一个作答点。典型不拆：“若…判断是否同时满足性质①和②”“从条件①②中选一个作为已知”“从①②③中选取两个作为条件，证明另外一个成立”。全库曾有 13 道数学题因此把条件标记误拆成 `①和（作答点）`、`②；` 这类 B 卡。
7. **数学公式内部的括号不是小问编号。** `$f(1)$`、`$a_n(2)$`、`$P(2<X\leqslant 2.5)$` 里的 `(1)(2)` 必须跳过；判定条件：编号位于 `$...$` 区间内，或编号前一个字符是 ASCII 字母/数字/`_`/`$`/`\`。全库实测有 2 题因此把单问题切成 `Q1 = '\"$的'`，修复后应为 0。
8. **编号命中后要回读子问正文。** 子问正文若只有 `= $`、`$\"的`、单个标点，说明切错了；不要拿它去建空白卡或 B 号，回到完整题干按“问号/分号/空位”重新切。

## 5.7 条件表与设问句的分界（全题型通用）

写“二、显性条件表”时，先判断一句话是**给条件**还是**提问题**。下面这些形态默认是设问，不得整句进 C 表：

1. 带下划线/横线空位：`……为____`、`……是______`；
2. 规范化后空位被压成空格：`……顺序是 ，从…说明理由`、`……该化合物是`；
3. 操作指令：`请作出…`、`试解释…`、`回答下列问题`、`完成下表`、`写出…`、`建立…模型`；
4. 选项整行：`A. … B. … C. … D. …`（选项归第四节逐项验证）。

**保留条件、丢掉设问尾巴**的做法：

- `向上述溶液中加入过量 NaOH 溶液，充分反应后过滤，滤渣为____`
  → C 行只留“向上述溶液中加入过量 NaOH 溶液，充分反应后过滤”。
- `Ag 分别与盐酸、氢溴酸、氢碘酸混合，Ag 只与氢碘酸发生置换反应，试解释原因`
  → C 行只留前两句，删“试解释原因”。
- `Y 岛的生态系统由岛上所有的生物与____共同组成`
  → 没有独立条件，整句不进 C 表；该空只进 B 表。

自检：C 表任意一行出现 `____` / `【空】` / `请…` / `试…`，即为不合格；全量批跑时用脚本扫描一次，目标为 0。

**表格竖线的特殊坑**：判断一行是不是 Markdown 表格前，先剥掉 `$...$` 数学段。数学绝对值 `$|\vec{PD}|$`、范数 `$\|x\|$` 里的 `|` 不是表格分隔符；否则真正的条件句会被整句跳过，C 表只剩“设问限定：…____”。输出时数学段内把 `|` 写成 `\vert`。

**空位 clue 的自检**：B 卡“判断依据”不能只剩 `①和（作答点）`、`②；`、`/【空】`。若预检 clue 太短，回到对应小问/原表行补上下文，并标“本小问第 n 个作答点”；仍无法定位时标“待核实”，不要用空标记交付。

## 6. 条件缺失与题面损坏

联网文字版或 OCR 常丢失公式、装置图、表格、单位。遇到这种情况：

1. 先列 G0“缺失项”：缺的是公式、图形、表格还是单位。
2. 只拆解题面已明确给出的条件；依赖缺失项的空编 B 号并标“待核实”。
3. 不猜图形、不补数值、不把相似题目的条件搬过来。
4. 给用户一句可执行的补充请求：需要补哪张图、哪个公式或哪一行表格。
