# 答案隔离、B 卡矩阵与官方解析核对

本文件是 shenti-coach 的**高风险环节**操作手册：批量跑题库时，最大的质量风险不是格式，而是把待填答案写进了条件表、隐含条件表、文本树或路径提示，以及答非所问。写完整八模块前后各过一遍本文件。

## 1. 一空一 B，先建 B 表

- 数清题面下划线/横线/括号中的空位，**再加上没有下划线的隐含作答点**（“说明理由/解释/求/证明/写出/在图中画出”）；一个作答点一个 B 号。多问用 `Q1-B1`、`Q2-B1`，或顺序 `B1…Bn` 并附“空号—小问—待填类型”映射表。显式空与隐含作答点合计就是 `answer_slots`，B 号必须覆盖全部 `answer_slots`。
- “答出 2 点即可”仍算 **1 个空**（一个 B），但作答要点必须覆盖 2 点；“两个指标”“两个变化”分别有两个下划线时算 2 个空。
- 生成后核对：`B 号数量 == answer_slots`（显式空 + 隐含作答点）；少一个就是漏空，多一个就是造空。只有纯选择题才可以用 `B 号数量 == 0`。
- 可用 `node scripts/check_output.mjs <输出.md> --type <题型> --blanks <显式空位数> --answer-slots <作答点总数>` 做数量自检；不传 `--answer-slots` 时默认等于 `--blanks`。

## 2. 官方解析核对（题库带 solution/analysis 时）

1. 先读官方解析，逐空写出“B 号 → 官方答案指纹”（一个最短可识别词组，如“细胞呼吸”“物质循环”“Fe(OH)₃胶体”）。
2. 核对 B 号与官方小问一一对应，尤其检查**一个空里是否其实有两问**、或**两个空被合并**。
3. 核对条件来源的**阶段边界**：Qn 只能用第 n 问之前或同阶段的已知，不得把后续步骤的产物当成前一步的答案。典型反例：题目问“滤液1 中铜的存在形式”，官方答案是蒸氨前的铜氨配离子，而输出拿“部分蒸氨后生成 CuS”去回答——这是答非所问，不是泄题。
4. 核对输出的隐含条件是否与官方解析矛盾；矛盾时以官方解析为准，标“待核实”只在官方解析本身缺失/含糊时使用。
5. 把答案指纹逐个在 `〇`–`六` 中搜索；命中即改写为“从…角度/判据/定义”的提示，不得保留可直接抄写的答案。
6. 文本与图片都要查：文本用 `check_output.mjs --answer <指纹>`；图片用 `render_bigbang.mjs ... --forbid <指纹>`。`--forbid` 命中时脚本以退出码 2 拒绝渲染，必须先改节点/连线文字再重跑。

## 3. 答案指纹隔离的边界

- **可以写**：答案类型（过程名/概念名/化学式/字母/正负/数值）、作答角度、判断依据、必须覆盖的要点、题干已给出的量、课标原文中的知识领域名。
- **不得写**：答案本身、答案的同义改写、把因果链写成完整句、在文本树节点或路径提示中给出可抄写的结论、把后续步骤的产物写进前一步的答案。
- **答案本身是教材术语时**：正文的“对应知识点/考纲与教材”列只能写该术语指向的**过程描述或结构特征**，不能写术语本身。例：答案是“逆转录”时，知识列写“以 RNA 为模板合成 DNA 的信息流”；答案是“感受态”时，写“Ca²⁺ 处理后易于吸收外源 DNA 的生理状态”。术语只保留在官方核对区/完整解答，不进入〇–六正文，也不进入图节点/连线。
- 开放空（原因/结论/措施/优点）按 `question-type-playbooks.md` 的三问自检执行；其他空同样适用，不得只查开放空。
- 发现泄漏时优先改写成“从…角度作答（Bn）”“需覆盖…要点（Bn）”“由 Cn 与 Cm 判断（Bn）”，不要用同义词替换继续泄题。

## 4. 空白作答卡：先建矩阵，再写八模块

空位 ≥2 时，先建下面这张卡，再写正文；卡里不写答案，只写“这一空要判断什么”。

| 空号 | 小问 | 待填类型 | 判断依据（不写答案） | 官方答案指纹已核对 |
| --- | --- | --- | --- | --- |
| B1 | Q1 | 名称/数值/化学式/原因/操作/标号 | 由 Cn 的哪个词触发什么判断 | 是/待核实 |

硬规则：

- **一空一行**；两个下划线就是两个 B，不因它们语义相近而合并。
- “答出 2 点即可”仍是一个空（一个 B），但在“判断依据”里写“需覆盖 2 个要点”，不要拆成 B1、B2。
- 每个 B 必须能回指到一个小问或“题首/未归类”；回指不到时先停，按题面原文核对，不猜。
- 多空之间存在依赖时，只写“B2 依赖 B1 的判断结果”，不把 B1 的答案代入 B2。
- 官方答案有小问编号时，B 表的小问列必须与官方编号对齐；对不上时先标“待核实”，不得强行凑数。

## 5. 答案指纹怎么选（避免“抓太宽”和“抓不到”）

1. 先从官方答案中取**最短可识别词组**；优先名词/化学式/数值+单位，不用“温度”“作用”“增大”这类高频词。
2. 做一次**题干减法**：指纹不能是题干已给出的原词（如题干已有“净水”，不要用“净水”当指纹；改从解析里取“Fe(OH)₃胶体”）。
3. 再做一次**同义扩展**：如果答案说“增大氧气溶解度”，指纹同时检查“溶解度”“溶解与供给”“O₂ 的溶解”等变体；只查原句会漏掉同义泄题。
4. 指纹放在 `〇`–`六` 命中即改写为角度/判据；`七、审题收获` 可以保留方法总结，但不得写答案。
5. 官方答案本身与题干条件同义、找不到独有指纹时（如答案就是题面已知的某个符号），标“指纹弱/人工核对”，不要把题面词硬当泄漏。

## 6. 多问题目的阶段边界卡（流程/实验/多材料题必做）

在“一、目标分析”后加一张极简阶段表：

| 阶段 | 这一阶段有什么 | 这一阶段还没有什么 | 对应小问 |
| --- | --- | --- | --- |
| 例如“氧压氨浸” | 滤液1、镍/铜的配位环境 | 还没有“部分蒸氨”后的沉淀 | Q1–Q3 |
| 例如“部分蒸氨” | NH₃ 减少、铜物种开始转化 | 还没有“转化”步骤的氧化 | Q3–Q4 |

写 Qn 时先看它落在哪一行：**只能用本行及以前阶段已出现的物料/条件**。如果输出里的答案来自后面一行，立即判为“阶段错位”，不是措辞问题。

## 7. 批跑闸门与产物

- 结构闸门：`node scripts/check_output.mjs <输出.md> --type <题型> --blanks <显式空数> --answer-slots <显式空+隐含作答点> --q-count <Q数> --require-blank-map --answer <答案指纹> --require-media`
- 人工语义复核完成后，才在命令末尾加 `--semantic-reviewed`；需要强制区分时可再加 `--strict-semantic`（未声明复核即 FAIL）。输出末尾会明确打印“结构 PASS / 语义 pending 或 done”。
- 严格泄题闸门：在上面的命令加 `--strict-answer`；答案指纹出现在 `〇`–`六` 直接 FAIL，不再只是 WARN。
- 图片闸门：`node scripts/render_bigbang.mjs <spec.json> <PNG> --forbid <答案指纹>`；命中退出码 2，不得交付该 PNG。
- 批跑清单：每题的 `preflight` 记录、输出 md、spec.json、PNG、check 结果、render 结果各留一份；没有这五件套不算“跑完”。

## 8. 全量批跑的四条结构性口径（2026-11-26 全库 1045 题实测）

这四条不是措辞偏好，而是**结构正确性**问题；全量跑题时逐条执行。

1. **C 表只放条件，不放设问。** 句子带下划线（`____`）、以“是 / 为 + 逗号或句号”收尾、或以“请 / 试 / 回答 / 完成 / 写出 / 作出 / 建立”开头时，先按设问处理：
   - 空位前还有真正的操作/数据条件（“向…中加入…，过滤，滤渣为____”）→ 只保留空位前的条件分句；
   - 纯设问（“Y 岛生态系统由…与____组成”“该化合物是”“规律是”）→ 整句不进 C 表；
   - A–D 选项整行不进 C 表，选项由第四节“逐项验证点”承接。
   全量实测：不做这一步时 C 表有 **510 行**把设问当条件；做完后为 **0**。
2. **小问编号必须排除数学公式内部。** `$f(1)$`、`$a_n(2)$`、`$P(2<X\leqslant 2.5)$` 里的 `(1)(2)` 不是小问；编号前一个字符是 ASCII 字母/数字/`_`/`$`/`\` 时一律跳过。否则会出现 `Q1 = '\"$的'` 这类残句（数学-北京-2021-q3、数学-辽宁-2022-q8 实测）。
3. **隐含条件规则要同时看题干、小问正文和知识点名。** 只看总题干会让生态/群落、二项式、向量、晶胞等题 H 表空成“未命中”；只看正文又会让教材词不出现的题漏触发。触发文本 = `stem + 各小问正文 + 真实知识点名`。选择题不套学科专项规则，只走选项互斥/逐项验证。
4. **答案指纹过滤造成 H 全空时，不许硬造，也不许把规则改写成答案。** 优先改写规则措辞避开答案原词（如生态规则不写“物质循环/能量流动”，改写“按输入—传递—散失梳理能量路径”）；仍无法避开时，H 表写“本题没有命中专项隐含条件（不硬造）；通用审题提醒见第七部分”，并在第七部分注明“已省略 N 条与答案同词的提示”。

## 9. 选择题与空位卡的六条质量闸门（2026-11-27 全库 1045 题复跑）

1. **选择题 H1 必须具体，通用“逐项验证”不得占 H 号。** H 表第一条应是题干专题（如“核反应质量数/电荷数守恒”）或选项级策略（单位/守恒/端点/绝对化/图像/因果方向）。只有在完全没有具体规则时，才用“逐项验证”兜底；已有具体 H 时，它只出现在第七部分。
2. **30 秒速览必须写出“问什么对象”。** 禁止 `选出：则（ ）`、裸“正确的一项/不合理的一项”、无对象的“所给说法/叙述/判断/结论”。应写成“由‘…’判断…”“该过程的运动学量”“核反应方程括号内应填的粒子”等。题干引号内对象优先，其次官方知识点名，结构词只做最后兜底。
3. **四个选项的验证角度必须逐项区分。** 同一类规则命中四个选项时，要在角度后补“本项核对：<该项关键系数/角度/符号/短证据>”；公式选项不能因 LaTeX 截断而四行都变成“…”；纯图片选项写“本项核对：选项 X 的图（对照 G 清单）”。
4. **C 表不把设问/空位当条件。** 纯选择题没有独立条件时，C1 可写“设问限定：…”；纯填空题只剩空位时，C1 写“题干给定对象：…”，不得抄 `____`、`【空】`、`\quad` 或空括号。表格竖线判断前先剥掉 `$...$` 数学段：`$|\vec{PD}|$` 的 `|` 是绝对值，不是 Markdown 表格分隔符。
5. **空白卡 clue 不能只剩标记。** `①和（作答点）`、`②；`、`/【空】` 这类 clue 不合格；应从对应小问/原表行补上下文，写成“针对题干列出的 ①②③④ 各项，正确结论的序号是【空】”或“原表相关行：N基因表达量：参照值 /【空】/【空】（本小问第 2 个作答点）”。
6. **①②③ 不一定是子任务。** “从条件①②中选一个”“性质①②”“①②③中选两个证明另一个”是条件/选项引用，不能按子任务拆 B；只有至少两个片段自带作答动词、作答落点或空位时，才逐个编 B。

## 10. 交付前答案隔离自检

- [ ] B 号数量 = `answer_slots`（显式空 + 隐含作答点）
- [ ] 每个 B 都能回指到小问/题首，没有“未归类”
- [ ] 官方答案指纹逐条在 `〇`–`六` 搜索过，命中已改写
- [ ] 阶段边界卡已建，Qn 没有引用后续阶段的产物
- [ ] 开放空三问自检通过（无待填词、无完整因果链、只留角度/要点）
- [ ] 图节点、连线、标题、脚注都过了 `--forbid`
- [ ] `check_output` 打印“结构 PASS”，语义状态如实标注 pending/done
